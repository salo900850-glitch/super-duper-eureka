CREATOR FITNESS — установка и публикация

Файлы:
- index.html — приложение
- manifest.webmanifest — настройки установки на главный экран
- sw.js — офлайн-кэширование
- icon.svg — значок

Как опубликовать бесплатно:
1. Создай аккаунт на https://github.com/
2. Создай новый публичный репозиторий, например creator-fitness.
3. Загрузи в корень репозитория все 4 файла (README можно тоже).
4. Открой Settings → Pages.
5. В разделе Build and deployment выбери Deploy from a branch, ветку main и папку /(root), нажми Save.
6. Подожди публикации. GitHub Pages покажет адрес сайта.
7. Открой адрес в Chrome на Android → меню ⋮ → Установить приложение или Добавить на главный экран.

Важно:
- Для установки PWA нужен сайт по HTTPS (GitHub Pages это поддерживает).
- Данные тренировок сохраняются локально в браузере этого устройства. Очистка данных браузера может удалить историю.
- Приложение не публикует данные в интернет и не требует аккаунта.
